# Pocket Science Lab Documentation

Welcome to the official documentation site for the **Pocket Science Lab (PSLab)**. 

This comprehensive resource provides full documentation for the PSLab ecosystem, including step-by-step guides, in-depth tutorials, and technical references.

---

### Getting Started
Learn the basics of the PSLab hardware, install the cross-platform applications, and set up your workspace to begin experimenting.

### Hardware & Firmware
Detailed instructions on understanding the hardware architecture, pinouts, and how to successfully flash the latest firmware to your PSLab device.

### Using the Instruments
Comprehensive tutorials and guides for utilizing the built-in laboratory instruments, including the oscilloscope, multimeter, logic analyzer, wave generator, and various advanced sensors.

### Contribution Guidelines
Join the open-source community! Find our contribution guidelines, learn how to navigate the codebase, report issues, and help translate the application.
